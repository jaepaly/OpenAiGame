# 구름 수확 (Sky Harvest)

브라우저에서 바로 실행되는 TypeScript 기반 액티브 인크리멘탈 게임 프로토타입입니다.

플레이어는 비행선을 직접 움직여 구름을 흡입·압축해 화물칸에 저장합니다. 짧은 수확 루프 안에서 콤보와 피버를 만들고, 원하는 순간 기지로 귀환해 화물 구성에 맞는 가공 계약을 선택합니다. 정산한 코인으로 영구 부품을 강화해 더 높은 고도로 진출하는 것이 목표입니다.

## 핵심 기능

- `WASD` 이동과 마우스 조준을 분리한 실시간 구름 흡입
- 기본 부채꼴 흡입과 피버 전용 360도 광역 흡입
- 흰 구름 → 비구름 → 전기구름 → 빙정구름 → 태양구름 → 오로라구름으로 이어지는 6단계 자원 성장
- 실시간 콤보, 5연속 `PRESSURE SURGE`, `SKY FEVER`
- 연쇄 기압폭발이 주변 구름을 0.04~0.08초 박자로 실제 수확하는 `CASCADE` 시스템
- 일반 수확과 피버의 카메라 진동·순간 정지를 낮추고 충격파·광선으로 속도감을 유지하는 시각 안정화
- 코인 3배·XP 2배를 제공하는 희귀 고밀도 구름
- 원형 군집·구름띠·밀집 덩어리로 등장하며 핵 수확 시 전체가 붕괴하는 구름 포메이션
- 기본 28칸부터 영구 연구·흡입구·오버드라이브로 크게 확장되는 화물칸
- 고도에 따라 3개에서 6개까지 열리는 구름 특화 가공 계약
- 하위 재료·장기 콤보, 고밀도 드론 채굴, 시작 피버·전선 잭팟으로 플레이 방식이 갈리는 3가지 항로
- 하루가 바뀌어도 레벨·XP·구름 재고·스킬망이 영구 누적되는 장기 커리어
- 2차 출격의 고밀도 운항과 3차 출격 전용 황금 수확 전선
- 하루 종료 시 선택해 다음 날에도 남기는 3종 영구 연구
- 16개에서 34개로 확장된 3계열 다단 스킬트리와 2차 궁극·교차 시너지
- 6단계 고도 승급과 기존 대비 약 3배로 확장된 영구 장비 상한
- 정산한 6종 구름을 단계별 재료로 소비하고 상위 구름을 하위 재료로 환산할 수 있는 개방형 설계도
- 흡입+피버, 흡입+자동화, 피버+자동화를 결합하는 3종 교차 시너지 시스템
- 사이클론 나선, 연쇄 예약선, 폭풍 드론 광선으로 빌드가 직접 드러나는 전용 필드 연출
- 흡입구 성장에 따라 최대 구름 수와 생성 속도가 함께 증가하는 후반 물량 성장
- 일반 생성과 별도로 최소 구름 재고선을 유지해 필드가 비지 않는 즉시 보충 시스템
- 다음 플레이에도 유지되는 정비소 영구 강화
- 강화 단계에 따라 달라지는 비행선 외형
- 기지 귀환 후 정비 베이·설계 터미널·출격 게이트를 직접 고르는 격납고 허브
- 기체를 떠나 구름을 추적하고 광선으로 수확하는 독립 행동형 드론 편대
- 고도마다 지형·날씨·태양·빙정·우주와 오로라가 달라지는 6종 하늘 배경
- 브라우저 `localStorage` 기반 자동 저장

## 실행 방법

```bash
pnpm install
pnpm dev
```

프로덕션 빌드:

```bash
pnpm build
pnpm preview
```

## 조작

- PC에서는 `WASD` 또는 방향키로 비행선을 움직이고 마우스로 흡입 방향을 조준합니다.
- 마우스 왼쪽 버튼을 누르고 유지하면 조준한 부채꼴 안의 구름을 흡입합니다.
- `Space`를 누르면 즉시 기지 귀환 절차를 시작합니다.
- 피버 중에는 흡입 범위가 360도로 확장됩니다.
- 터치 기기에서는 화면을 누른 위치로 이동하며 주변 구름을 간편하게 흡입합니다.
- 구름을 연속으로 수확해 콤보와 피버 게이지를 유지합니다.
- 자동 수확 트리의 연쇄 기압폭발을 해금하면 한 구름에서 시작한 압축 폭발이 주변 구름으로 번집니다.
- 화물을 모은 뒤 우측 하단 `기지 귀환` 버튼으로 공장에 복귀합니다.
- 현재 화물에서 가장 높은 정산액을 제공하는 가공 계약을 선택합니다.
- 첫 두 번의 정산 뒤에는 레벨과 장비가 유지되며, 세 번째 정산 뒤 영구 연구를 선택합니다.
- 다음 출격 전 순풍 회랑, 고기압 광맥, 전선 추적로 중 하나를 선택합니다.
- 정산한 구름은 회사 창고에 종류별로 쌓이며, 귀환 후 이를 소비해 흡입 폭주·황금 피버·자동 수확 노드망을 조립합니다.
- 특성 노드 42개를 모두 해금하면 무한 연구 탭이 열리며, 구름 질량을 반복 투자해 속도·흡입 출력·연료·드론·수확 가치를 제한 없이 성장시킬 수 있습니다.
- 프롤로그·첫 안전 귀환·비구름 항로 해금 장면을 통해 작은 회사의 재건과 쾌청산업의 구름 독점 미스터리가 진행됩니다.
- 좌측 하단 정비소에서 영구 부품을 강화합니다.
