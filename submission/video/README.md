# 구름 수확 회사 — 제출용 데모 영상

목표 길이: 약 55초 (대회 요구사항인 3분 이내)

## 구성

1. 타이틀과 게임 콘셉트
2. 초반 구름 수확
3. 저연료 `LAST HARVEST`와 안전 귀환
4. 가공 계약 및 특성 성장
5. 후반 오로라 항로 대량 수확
6. 대량 가공과 비행 리포트

영상은 실제 브라우저 플레이 장면으로 구성하며, 평상시에는 수확 효과음만 들리고 후반 피버 장면에서만 음악이 강해집니다. 사용된 오디오는 프로젝트를 위해 직접 합성한 원본입니다.

최종 파일: `sky-harvest-company-demo-ko.mp4`
